## Nightstand

Nightstand is an experimental, installable bedside clock for iPad. The current beta is hosted at:

- **App:** https://fganime.github.io/nightstand/
- **Documentation and setup:** [nightstand/README.md](nightstand/README.md)
- **Change history:** [CHANGELOG.md](CHANGELOG.md)

Nightstand is currently a personal-use web app/PWA beta, not an App Store release. Its live indoor sensor integration is configured for one specific local Homebridge proxy and is not yet suitable for general distribution.
